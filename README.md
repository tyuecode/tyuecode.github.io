# strokeoil · 油画工序逐笔重绘

把任意图片重绘成「按真实油画十道工序逐笔画出」的动画。**纯前端实现，图片不上传、无需后端**，可直接托管到 GitHub Pages。

仓库：<https://github.com/tyuecode/tyuecode.github.io>

在线体验：<https://tangyue.me/>

## 特点

- 🎨 **真实油画工序**：刷底色 → 起稿 → 单色底层 → 铺大色 → 塑造 → 塑形 → 罩染 → 干扫 → 细部 → 提白，十道工序顺序严格
- 🖌 **物理笔触**：起收锋、笔毛分叉、颜料渐枯、厚涂浮雕、罩染透叠
- 📱 **响应式**：桌面双栏、移动端单栏，自动适配触屏
- 🔒 **本地处理**：图片只在你的浏览器里，绝不联网上传
- 📦 **可下载**：生成结果打包成单个 HTML 文件，双击离线播放、随意分享
- ⚡ **快**：1500px 图约 1.5–3 秒，8 万条笔触

## 使用

1. 打开网站（或本地 `python -m http.server` 后访问）
2. 拖入 / 选择图片（PNG / JPG / WEBP）
3. 调「细腻程度」「动画时长」「处理精度」
4. 点「开始生成」
5. 页面内实时预览，或下载单文件播放器

## 算法原理

**分层定色、结构张量定走向、工序定笔触语言、串行时间轴定节奏。**

1. **五层明暗分层**：在 L\*（亮度）× S（饱和度）平面上做 k-means，把人像与背景按材质分开
2. **轮廓与方向**：Canny 提取边缘，结构张量（Sobel → 特征分解）求每一笔的走向；平坦区改用低频方向场，避免笔触乱指
3. **十道工序**：每道工序有自己的笔宽、密度、透明度与颜色处理，宽度逐档过渡（否则细笔硬盖巨笔会毛躁）
4. **严格串行**：`start[i] == start[i-1] + dur[i-1]`，逐条校验零重叠零断点
5. **颜色取自原图**：沿笔触取中位色，只做轻微抖动，绝不用调色板

## 部署到 GitHub Pages

仓库本身就是 Pages 站点，`main` 分支 + GitHub Actions 自动部署。

换成你自己的域名：改 `CNAME` 文件内容即可。

其他静态托管（Cloudflare Pages / Netlify / Vercel）同样适用——四个静态文件，无构建步骤。

## 本地开发

```bash
python -m http.server 8000
# 访问 http://localhost:8000/
```

> 注意：不要用 `file://` 直接双击 `index.html`，Web Worker 和 fetch 会被浏览器拦截。
